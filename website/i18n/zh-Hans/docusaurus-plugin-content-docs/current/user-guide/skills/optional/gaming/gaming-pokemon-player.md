# Pokemon Player

使用 `pokemon-agent` 包通过无头模拟运行宝可梦游戏。

## 何时使用
- 用户说 "play pokemon"、"start pokemon"、"pokemon game"
- 用户询问宝可梦红版、蓝版、黄版、火红版等
- 用户想观看 AI 玩宝可梦
- 用户提到某个 ROM 文件（.gb、.gbc、.gba）

## 启动流程

### 1. 首次设置（克隆、创建 venv、安装）
仓库是 GitHub 上的 NousResearch/pokemon-agent。先克隆它，然后
搭建一个 Python 3.10+ 虚拟环境。使用 uv（速度更快，优先选择）
创建 venv，并以可编辑模式安装该包，同时启用 pyboy extra。
如果没有 uv，则回退到 python3 -m venv + pip。

在这台机器上，它已经安装在 /home/teknium/pokemon-agent，
venv 也已就绪——只需 cd 过去并 source .venv/bin/activate。

你还需要一个 ROM 文件。请向用户索取他们自己的 ROM。在这台机器上，
该目录内的 roms/pokemon_red.gb 已存在一个。
切勿下载或提供 ROM 文件——始终向用户索取。

### 2. 启动游戏服务器
在已激活 venv 的 pokemon-agent 目录中，运行
pokemon-agent serve，其中 --rom 指向 ROM，--port 为 9876。
用 & 让它在后台运行。
要从存档恢复，请加上 --load-state 并指定存档名。
等待 4 秒完成启动，然后用 GET /health 验证。

### 3. 搭建实时仪表板供用户观看
通过 localhost.run 使用 SSH 反向隧道，让用户可以在浏览器中
查看仪表板。用 ssh 连接，把本地 9876 端口转发到
nokey@localhost.run 的远程 80 端口。将输出重定向到日志文件，
等待 10 秒，然后在日志中 grep 出 .lhr.life URL。
把该 URL 加上 /dashboard/ 后缀交给用户。
隧道 URL 每次都会变化——如果重启了，请把新的 URL 给用户。

## 动作参考
- press_a —— 确认、对话、选择
- press_b —— 取消、关闭菜单
- press_start —— 打开游戏菜单
- walk_up/down/left/right —— 移动一格
- hold_b_N —— 按住 B 键 N 帧（用于快速跳过文本）
- wait_60 —— 等待约 1 秒（60 帧）
- a_until_dialog_end —— 反复按 A 直到对话结束

## 来自实战的关键技巧

### 持续使用视觉
- 每移动 2-4 步就截一次图
- RAM 状态告诉你位置和 HP，但**不会**告诉你周围有什么
- 台阶、栅栏、告示牌、建筑门口、NPC —— 只有截图才看得到
- 向视觉模型提出具体问题："我北边一格是什么？"
- 卡住时，务必先截图，再尝试随机方向

### 传送切换需要额外等待时间
穿过门或楼梯时，屏幕会在地图切换期间淡入黑色。
你**必须**等待它完成。在任何门/楼梯传送后加上 2-3 个 wait_60
动作。不等待的话，读到的位置是过期的，你会以为自己还在旧地图上。

### 出建筑的陷阱
离开建筑时，你会正好出现在门的**前方**。
如果向北走，就会直接又走回屋里。**务必**先向左或向右
横移 2 格，然后再朝你想去的方向前进。

### 对话处理
第一世代的文本是逐字母缓慢滚动的。要快速跳过对话，
按住 B 键 120 帧，然后按 A。按需重复。按住 B 会让
文本以最快速度显示。然后按 A 推进到下一行。
a_until_dialog_end 动作会检查 RAM 中的对话标志，但该标志
并不能覆盖**所有**文本状态。如果对话看起来卡住了，请改用手动的
hold_b + press_a 组合，并通过截图验证。

### 台阶是单向的
台阶（小的悬崖边缘）只能向**下**（南）跳，绝不能向**上**（北）爬。
如果向北被台阶挡住，你必须向左或向右寻找绕过它的缺口。
用视觉判断缺口在哪个方向。请明确地询问视觉模型。

### 移动策略
- 每次移动 2-4 步，然后截图检查位置
- 进入新区域时立即截图以确定方位
- 询问视觉模型 "去[目的地]该往哪个方向？"
- 如果连续 3 次以上卡住，截图并彻底重新评估
- 不要一次塞 10-15 个移动动作——你会走过头或卡住

### 从野生战斗中逃跑
在战斗菜单中，RUN 位于右下角。要从默认光标位置
（FIGHT，左上角）到达它：先按下，再按右，把光标移到 RUN，
然后按 A。外面套上 hold_b 以快速跳过文本/动画。

### 战斗（FIGHT）
在战斗菜单中，FIGHT 位于左上角（默认光标位置）。
按 A 进入招式选择，再按 A 使用第一个招式。
然后按住 B 快速跳过攻击动画和文本。

## 战斗策略

### 决策树
1. 想要捕捉？ → 削弱后投出精灵球
2. 不需要的野生宝可梦？ → 逃跑（RUN）
3. 有属性克制优势？ → 使用效果拔群的招式
4. 没有优势？ → 使用最强的本系（STAB）招式
5. HP 过低？ → 换人或使用伤药

### 第一世代属性相克表（关键克制）
- 水 克 火、地面、岩石
- 火 克 草、虫、冰
- 草 克 水、地面、岩石
- 电 克 水、飞行
- 地面 克 火、电、岩石、毒
- 超能力 克 格斗、毒（在第一世代中极其强势！）

### 第一世代的特殊机制
- 特殊（Special）数值同时决定特殊招式的攻击**与**防御
- 超能力属性过强（幽灵系招式存在 bug）
- 会心一击概率由速度数值决定
- 紧束/绑紧类招式会让对手无法行动
- 聚气（Focus Energy）的 bug：会**降低**会心率，而不是提高
