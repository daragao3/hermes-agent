# CLI 符号速查表

Hermes 的终端界面使用一套紧凑的视觉语言：圆点、尖括号、盲文加载动画和状态字形。本页就是它的解码手册。内容覆盖 [TUI](../user-guide/tui.md)（大多数符号在这里渲染），并注明了与 [经典 CLI](../user-guide/cli.md) 共享的部分。

:::note 皮肤可以重新设计其中一部分
下方标注为*可主题化*的字形是品牌默认值——[皮肤](../user-guide/features/skins.md) 可以覆盖它们（例如 `tool_prefix` 和提示符）。其余符号都固定在渲染器中。
:::

## 对话记录符号 {#transcript-symbols}

agent 工作时你在对话流中看到的内容。

| 符号 | 含义 |
|--------|---------|
| `❯` | 输入提示符——你在这里输入。*可主题化*（皮肤会设置自己的提示符）。 |
| `●` | 一次工具调用。圆点位于工具名称及其参数之前。 |
| `┊` | 与工具行一同显示的工具活动竖线。*可主题化*（`tool_prefix`）。 |
| `✓` / `✗` | 工具结果：成功 / 失败。附加在已完成工具行的末尾。 |
| `▸` / `▾` | 折叠 / 展开的分区尖括号（思考、工具、subagent、横幅分区）。点击可切换。 |
| `▍` | 流式输出光标——模型仍在输出文本时闪烁。 |
| `│` `├─` `└─` | 树形连线——将父项（一次委派、一段旅程）与其子条目相连；`└─` 标记最后一个子项。 |
| `◈` | 仅用于显示的时间线事件（内联渲染的会话通知，而非用户消息）。 |
| `◇` | 注入的引用块，例如 `◇ Reference 1/2 — <label>`。 |
| `↳` | 置顶提示——回显 agent 当前正在处理的用户消息。 |
| `☐` / `☑` / `•` | Markdown 任务列表项（未完成 / 已完成）以及普通列表圆点。 |
| `▶` | 渲染后 markdown 中折叠的 `<details>` 摘要。 |

## 状态栏符号 {#status-bar-symbols}

TUI 底部的单行状态栏。各段只在相关时出现，在窄终端上会最先被省略。

| 符号 | 含义 |
|--------|---------|
| `⠋⠙⠹…`（盲文图案） | 忙碌加载动画。思考阶段和工具阶段使用不同的盲文动画组。 |
| `⚕ 🌀 🤔 ✨ 🍵 🔮` | `emoji` 忙碌指示器样式的各帧（`/indicator emoji`）。默认样式则轮换颜文字表情。 |
| <code>&#124; / - &#92;</code> | `ascii` 忙碌指示器样式的各帧。 |
| `⏱` | 轮次运行期间每条提示的已用时间，例如 `⏱ 12s/3m 45s`（轮次时间 / 会话时间）。 |
| `⏲` | 同一个计时器，在轮次完成后冻结。 |
| `cmp N` | 会话已被自动压缩 N 次。 |
| `▶ N` | 当前正在运行的 N 个 `/bg` 任务。 |
| `⚠ YOLO` | YOLO 模式已开启（自动审批）。也会显示在启动横幅中。 |
| `⛓ N` | 当前活动的 N 个 subagent。 |
| `↩ resumes when subagent finishes` | 当你处于空闲但委派的工作仍在进行时显示的安心提示——结果会自行返回。 |
| `● REC` | 语音模式正在录音。 |
| `◉ STT` | 语音录制已停止；语音转文字正在转写。 |
| `◉ focus` | 专注视图已开启（精简输出）。已固定，因此在窄终端上也不会被省略。 |
| `♥` | 好感闪现——Hermes 注意到你对它很友善。 |
| `⚡` / `🔋` | 电池指示器（需主动开启）：接通电源 / 使用电池，并显示百分比。 |
| `N bg` | 本会话中跟踪的 N 个后台终端进程。 |
| `N live sessions` | 本进程中打开的 TUI 会话——点击可打开会话切换器。 |

## 通知 {#notices}

短暂显示的状态栏通知带有各自的前导字形，由严重程度决定：

| 符号 | 含义 |
|--------|---------|
| `✓` | 成功通知。 |
| `•` | 信息通知。 |
| `⚠` | 警告（也用于额度警告）。 |
| `✕` | 错误通知。 |

## 审批与确认提示 {#approval-and-confirmation-prompts}

| 符号 | 含义 |
|--------|---------|
| `⚠ approval required` | 某个工具想要运行需要你明确同意的操作（带边框的面板，含命令预览）。 |
| `⚠` / `?` | 确认对话框标题：危险操作 / 普通问题。 |
| `🔐` | Sudo 密码提示（输入会被遮盖）。 |
| `🔑` | 凭据/密钥输入提示（输入会被遮盖）。 |

## Subagent 浮层（`/agents`） {#subagents-overlay-agents}

| 符号 | 含义 |
|--------|---------|
| `●` | Subagent 运行中。 |
| `○` | 排队中。 |
| `✓` | 已完成。 |
| `■` | 已中断。 |
| `✗` | 已失败。 |
| `⌛` | 已超时。 |
| `⚠` | 出错。 |
| `⚡N` | 汇总行中当前活动的 N 个 agent。 |
| `▁▂▃▄▅▆▇█` | 活动迷你图——每个分支最近的事件量。 |

## 会话切换器（`Ctrl+X`） {#session-switcher-ctrlx}

| 符号 | 含义 |
|--------|---------|
| `✓` | 会话空闲。 |
| `…` | 启动中。 |
| `?` | 等待输入。 |
| `▶` | 工作中。 |
| `✎ draft` | 该会话的输入框中有一份未发送的草稿。 |

## 选择器与中心面板 {#pickers-and-hubs}

| 符号 | 含义 |
|--------|---------|
| `▸` | 当前选中行（模型选择器等）。 |
| `*` | 当前激活的模型 / 提供商。 |
| `●` / `○` | 提供商已认证 / 未认证（模型选择器）；插件状态的回退显示（插件中心）。 |
| `✓` / `✗` | 插件已启用 / 已禁用（插件中心）。 |
| `↑ N more` / `↓ N more` | 列表可见窗口上方/下方还有更多行。 |
| `┃` | 可滚动浮层上的滚动条滑块。 |

## 目标 {#goals}

目标生命周期通知（来自 [目标](../user-guide/features/goals.md)）以其状态开头：

| 符号 | 含义 |
|--------|---------|
| `✓` | 目标已完成。 |
| `↻` | 目标继续——已安排下一次迭代。 |
| `⏸` | 目标已暂停。 |
